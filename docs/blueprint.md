# **App Name**: CrucibleOS Pulse

## Core Features:

- OS Name Header: Prominent display of the Open Source OS name in a distinct header section.
- Core Functionalities Display: Dedicated section detailing the key features and capabilities of the Open Source OS.
- Disclaimer Section: A prominent and distinct area presenting the disclaimers: 'Not intended for use in California or New York' and 'Has not been audited'.
- Notify Me Call-to-Action: A 'Notify When available' button that allows users to express interest in the OS.
- Email Collection & Storage: Backend system to collect and securely store user email addresses when the 'Notify When available' button is clicked.
- AI-Powered Feature Explanation Tool: An AI tool that provides concise, easy-to-understand explanations for technical OS features, improving user comprehension of core functionalities.

## Style Guidelines:

- Primary color (dark blue): '#173C7A' (HSL: 220, 70%, 30%). This deep blue evokes professionalism and reliability, aligning with the technical nature of an OS.
- Background color (very dark blue-grey): '#16191D' (HSL: 220, 15%, 10%). A heavily desaturated, dark blue-grey that provides a stark yet sophisticated contrast for content.
- Accent color (electric blue): '#3CCCF5' (HSL: 190, 80%, 60%). A vibrant, electric blue analogous to the primary hue, providing a high-tech accent for CTAs and highlights.
- Headline font: 'Space Grotesk' (sans-serif), chosen for its modern, tech-oriented aesthetic suitable for titles and short, impactful statements. Body font: 'Inter' (sans-serif), for its clear, neutral, and readable qualities suitable for longer descriptions and general text.
- Minimalistic, crisp line icons that reflect modern technology and operating system concepts. Prefer SVG formats for scalability.
- A clean, spacious layout with distinct sections for header, core functionalities, and disclaimers. Utilize grid-based structures for organized content presentation and emphasize hierarchy through font sizes and spacing. The 'Notify When available' CTA should be centrally prominent.
- Subtle, smooth hover effects on interactive elements like the call-to-action button and navigation links. Consider understated fade-in or slide-up animations for sections as the user scrolls, to enhance engagement without being distracting.
